# Repository Multimedia — Ringkasan Tugas dan File

Repositori ini berisi tugas multimedia (audio, video, image, sinyal) dan worksheet yang dikerjakan. Di bawah ini ringkasan struktur file dan tugas per worksheet sehingga mudah dinavigasi.

## Struktur & File utama
- `pdf.py` — skrip terkait pemrosesan/ekspor PDF.
- `convert_to_html.py` — konversi file ke HTML.
- `README.md` — file ini.
- `report.md` — laporan rPPG (worksheet 5).

## Worksheet 1
- `worksheet1/Naufal Haris N_Multimedia_Tugas1.pdf` — hasil tugas (PDF).
- Folder lingkungan/asset: `worksheet1/multimedia-uv/`

## Worksheet 2
- `worksheet2/122140040_worksheet2.html` — laporan HTML.
- `worksheet2/122140040_worksheet2.ipynb` — notebook Jupyter.
- Data terkait: `worksheet2/data/`

## Worksheet 3 (Audio)
- `worksheet3/122140040_handson_audio_clean.html` — laporan bersih (HTML).
- `worksheet3/122140040_handson_audio.ipynb` — notebook Jupyter analisis audio.
- `worksheet3/122140040_handson_audio.pdf` — versi PDF laporan.
- Analisis & gambar: `worksheet3/audio/`
- Hasil filtering: `worksheet3/hasil_filtering/`

## Worksheet 4 (Image & Video Processing)
- `worksheet4/122140040_worksheet4_clean.html` — laporan HTML.
- `worksheet4/122140040_worksheet4.ipynb` — notebook Jupyter.
- Asset gambar/video: `worksheet4/assets_ws4/`
- Hasil dan output: `worksheet4/results_ws4/`

## Worksheet 5 (Real-time rPPG)
- `worksheet5/rppg.py` — kode utama rPPG (deteksi detak jantung dari webcam secara real-time).
- `laporan_worksheet5.md` — laporan analisis dan hasil rPPG.

## Tujuan & Catatan tugas
- **Worksheet 1:** Pengumpulan tugas multimedia dasar (PDF).
- **Worksheet 2:** Eksperimen dengan gambar, video, dan suara (notebook dan HTML).
- **Worksheet 3:** Analisis dan filtering audio — notebook, visualisasi, dan hasil filtering.
- **Worksheet 4:** Pengolahan citra dan video, analisis hasil, dan visualisasi (notebook, HTML, asset, dan output).
- **Worksheet 5:** Implementasi rPPG real-time (deteksi detak jantung dari webcam), analisis sinyal, dan laporan hasil.

## Cara membuka file
- Notebook: buka file `.ipynb` dengan Jupyter / VSCode.
- Laporan HTML/PDF: buka file HTML/PDF di browser atau PDF viewer.
- Media: lihat di folder data/asset masing-masing worksheet.
- Untuk rPPG: jalankan `rppg.py` di worksheet5 dengan Python dan pastikan webcam aktif.

---

**Catatan:**
- Setiap worksheet berisi file utama, data, dan hasil analisis sesuai topik multimedia yang dipelajari.
- Untuk detail pipeline dan analisis rPPG, lihat `report.md` di worksheet5.
